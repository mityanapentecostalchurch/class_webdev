WEEK 7 PRACTICAL

One website. Different screen sizes.

Responsive Web Design allows a website to adjust its layout to phones, tablets, laptops and desktop computers. Resize this browser window to observe the changes.

Learning outcomes

By the end of this practical, students should be able to:

  • Explain the purpose of the viewport meta tag and media queries.
  • Build flexible layouts using CSS Grid and Flexbox.
  • Make images, tables and forms usable on narrow screens.
  • Test a webpage at desktop, tablet and mobile widths.

Learning beyond the classroom

Images should not overflow their containers. The rule max-width: 100%; height: auto; lets an image shrink while preserving its proportions.

Try temporarily changing max-width: 100% to width: 600px in the CSS, then observe what can happen on a narrow screen. Restore the responsive rule afterwards.

Example 5: Fluid typography and spacing

Notice that the main heading and section padding adjust with the available screen width. The CSS function clamp(minimum, preferred, maximum) helps prevent text from becoming too small or too large.

Example: font-size: clamp(1.7rem, 4vw, 2.8rem);

Practical tasks

  1. Open the page in a desktop browser and record how many card columns you see.
  2. Open Developer Tools and activate the device toolbar. Test a tablet and a phone viewport.
  3. Change the tablet breakpoint from 800px to 900px. What changes?
  4. Change the mobile breakpoint from 560px to 650px. Test again.
  5. Temporarily remove flex-direction: column from the mobile rule. Describe what happens to the hero and image layout.
  6. Check that no text or image spills outside the viewport and that the table can be scrolled horizontally.

Responsive design checklist

  • Viewport meta tag is present.
  • Images use max-width: 100% and height: auto.
  • Layout uses flexible units, Flexbox or CSS Grid.
  • Media queries adjust the layout at appropriate breakpoints.
  • Navigation, forms and tables remain usable on a phone.
  • Content is readable without zooming in or scrolling the whole page sideways.
