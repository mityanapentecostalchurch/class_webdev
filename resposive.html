Week 7: Responsive design notes

The same layout components used in Week 6 are now adapted to different screen sizes.

Flexible widths

The main content uses a percentage-based width with a maximum width, preventing it from becoming too wide.

Media queries

CSS breakpoints reduce grid columns and stack the main sections on narrower screens.

Responsive components

Navigation, course cards, forms, tables and media have specific rules for small viewports.

Responsive layout checklist

  • Viewport meta tag is present.
  • Course cards change from two columns to one column on smaller screens.
  • Form fields fit the available width.
  • Wide tables can scroll horizontally without stretching the whole page.
  • Audio and video players stay within their cards.
  • Navigation links wrap and remain usable.
