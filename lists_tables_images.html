1. Purpose of the Week 3 Practical

Week 3 extends the HTML webpage created in Week 2. Students move from basic document structure and text organisation to adding richer and more useful content: lists, hyperlinks, images, alternative text and tables.

The emphasis is on understanding what each HTML element is used for and applying it appropriately in a real webpage.

Students should continue using the same GitHub repository from Week 2. The existing webpage should be upgraded rather than replaced by an unrelated project.

2. Week 3 Learning Outcomes

By the end of the practical work, students should be able to:

  1. Create unordered lists.
  2. Create ordered lists.
  3. Create nested lists.
  4. Create and test hyperlinks.
  5. Create external links.
  6. Create links to other pages.
  7. Create email links.
  8. Open a link in a new browser tab.
  9. Insert images into an HTML webpage.
  10. Use the src attribute correctly.
  11. Use meaningful alternative text with the alt attribute.
  12. Organise local images in an images folder.
  13. Create basic HTML tables.
  14. Use <table>, <tr>, <th> and <td>.
  15. Combine lists, links, images and tables in one webpage.
  16. Test the webpage in a browser.
  17. Commit and push the completed work to GitHub.

4. Practical Topic 1 : Unordered Lists

An unordered list is used when the order of items is not important. The <ul> element creates the list and <li> creates each list item.

Basic example

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Example for an education webpage

<h2>Our Programmes</h2>

<ul>
    <li>Computer Science</li>
    <li>Information Systems</li>
    <li>Education</li>
    <li>Business Administration</li>
</ul>

Student practice

  • Add at least one meaningful unordered list.
  • Use information appropriate to the group's scenario.
  • Use lists to improve the organisation of information.

5. Practical Topic 2 : Ordered Lists

An ordered list is appropriate when the sequence of items matters. It is created using <ol> and <li>.

Example

<ol>
    <li>Choose a programme</li>
    <li>Complete the application form</li>
    <li>Submit the required documents</li>
    <li>Receive confirmation</li>
</ol>

Suggested processes

  • Education: applying or joining a programme.
  • Beauty Salon: booking a service.
  • Restaurant: placing an order.
  • Library: borrowing a book.

6. Practical Topic 3 : Nested Lists

A nested list is a list placed inside another list. Nested lists are useful when information has categories and subcategories.

Example

<ul>
    <li>Computing
        <ul>
            <li>Computer Science</li>
            <li>Information Systems</li>
            <li>Software Engineering</li>
        </ul>
    </li>

    <li>Business
        <ul>
            <li>Accounting</li>
            <li>Marketing</li>
            <li>Finance</li>
        </ul>
    </li>
</ul>

Student practice

Create at least one nested list that is meaningful to your group's scenario.

Example concept for a library

  • Books
    • Textbooks
    • Reference Books
  • Journals
    • Academic Journals
    • Research Journals
  • Digital Resources
    • E-books
    • Online Databases

7. Practical Topic 4: Hyperlinks

Hyperlinks allow users to move from one webpage or resource to another. The <a> element uses the href attribute to specify the destination.

7.1 External link

<a href="https://www.example.com">Visit Website</a>

7.2 Open a link in a new tab

<a href="https://www.example.com" target="_blank">
    Visit Website
</a>

Students should understand that target="_blank" instructs the browser to open the destination in a new tab or window, depending on browser behaviour.

7.3 Email link

<a href="mailto:info@example.com">
    Email Us
</a>

7.4 Link to another page

<a href="about.html">About Us</a>

This introduces the idea of a multi-page website. The linked file must exist at the specified location.

Student practice

  • Create and test at least two external hyperlinks.
  • Practise an email link or a link to another page.
  • Check every link before committing the work.

8. Practical Topic 5 : Images and Alternative Text

Images make webpages more informative and visually meaningful. The <img> element is used to place an image on a webpage.

Basic image example

<img src="images/campus.jpg"
     alt="Students walking around the university campus">

Important attributes

  • src: identifies the image location or source.
  • alt: provides alternative text describing the relevant image content or purpose.

8.1 Organising images

project/
├── index.html
└── images/
    ├── campus.jpg
    ├── students.jpg
    └── library.jpg

8.2 Referencing a local image

<img src="images/students.jpg"
     alt="Students working together in a computer laboratory">

8.3 Meaningful alternative text

Compare:

<img src="images/salon.jpg">

with:

<img src="images/salon.jpg"
     alt="Beauty salon interior with styling chairs">

Students should avoid vague alternative text such as "image" or "photo".

Student practice

  • Add at least two relevant images.
  • Store local images in the images folder.
  • Give every image meaningful alternative text.
  • Check that the image path is correct.

9. Practical Topic 6 : HTML Tables

Tables organise information into rows and columns. Students should understand the purpose of <table>, <tr>, <th> and <td>.

Element Purpose
<table> Creates the table.
<tr> Creates a table row.
<th> Creates a heading cell.
<td> Creates a data cell.

Basic table example

<table>
    <tr>
        <th>Item</th>
        <th>Price</th>
    </tr>

    <tr>
        <td>Hair Styling</td>
        <td>30,000 UGX</td>
    </tr>

    <tr>
        <td>Manicure</td>
        <td>20,000 UGX</td>
    </tr>
</table>

Suggested table focus by group

Group Suggested Table Suggested Columns
Education Programme catalogue Programme, Duration, Award
Beauty Salon Services and prices Service, Description, Price
Restaurant Menu Food, Category, Price
Library Resources Resource, Category, Availability

12. Browser Testing

Before committing the work, students should check:

  • All lists display correctly.
  • Nested list items appear under the correct parent item.
  • Hyperlinks open the intended destination.
  • Images display correctly.
  • Image paths are correct.
  • Meaningful alternative text is provided for images.
  • The table has clear headings and correctly organised rows and cells.
  • There are no obvious HTML syntax errors.
  • The page remains readable and logically organised.
